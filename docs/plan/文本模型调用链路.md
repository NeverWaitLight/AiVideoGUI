# 文本模型调用链路文档

本文档描述了 AI 视频生成工具中涉及文本大模型调用的主要业务流程及其技术实现链路。

---

## 架构概览

所有文本模型调用统一通过以下架构实现：

```
UI (QML) 
  ↓ 调用 Bridge 方法
Bridge Layer (Python QObject)
  ↓ 调用 Service
Service Layer
  ↓ 使用 ChatPromptBuilder 构建 Prompt
ChatPromptBuilder
  ↓ 加载 YAML 模板
PromptTemplateManager
  ↓ 返回 PromptTemplate
ChatPromptBuilder
  ↓ 构建 messages 列表
ChatService
  ↓ 调用 DashScope API
DashScope Text Generation API (HTTP POST)
  ↓ 返回 JSON 响应
ChatService
  ↓ 解析响应 & 保存任务记录
生成结果返回给 Service
  ↓ 解析结构化数据（如场次、分镜、角色）
Parser 工具（ScriptParser/ShotParser/CharacterParser）
  ↓ 返回结构化数据
Service 保存到数据库
  ↓ 通知 UI 更新
Bridge 发送信号给 QML
```

## 核心组件说明

### 1. ChatPromptBuilder (`../../prompts/chat_prompt_builder.py`)

**作用：** 文本大模型提示词构建器的统一入口类，封装所有文本模型的 Prompt 组装逻辑。

**依赖：** `PromptTemplateManager`（通过 DI 容器注入）

**主要方法：**
- `build_outline_optimization_messages()` - 大纲优化
- `build_script_generation_messages()` - 剧本生成
- `build_storyboard_generation_messages()` - 分镜生成
- `build_design_image_prompt_messages()` - 分镜设计图提示词生成
- `build_character_generation_messages()` - 角色生成
- `build_character_design_image_prompt_messages()` - 角色设计图提示词生成
- `build_screenplay_optimization_messages()` - 剧本优化
- `build_character_optimization_messages()` - 角色优化
- `build_storyboard_optimization_messages()` - 分镜优化
- `build_cover_image_prompt_messages()` - 项目封面图提示词生成

### 2. PromptTemplateManager (`../../prompts/manager.py`)

**作用：** 管理所有 YAML 配置文件中的提示词模板。

**模板文件位置：** `prompts/templates/*.yaml`

**模板结构：**
```yaml
system_prompt: |
  系统提示词内容

few_shot_examples:
  - user: "用户输入示例"
    assistant: "助手回复示例"

user_prompt_template: |
  用户提示词模板，支持 {variable} 占位符
```

**加载时机：** 应用启动时通过 DI 容器初始化，一次性加载所有模板。

### 3. ChatService (`../../service/chat_service.py`)

**作用：** 统一的文本模型调用接口，封装 DashScope API 的 HTTP 请求逻辑。

**核心方法：**
- `chat()` - 通用对话接口（底层实现）
- `optimize_story_outline()` - 优化大纲
- `generate_script()` - 生成剧本
- `generate_storyboard()` - 生成分镜
- `generate_design_image_prompt()` - 生成分镜设计图提示词
- `generate_character_design_image_prompt()` - 生成角色设计图提示词
- `generate_characters()` - 生成角色
- `optimize_screenplay()` - 优化剧本
- `optimize_characters()` - 优化角色
- `optimize_storyboard()` - 优化分镜
- `generate_cover_image_prompt()` - 生成项目封面图提示词

**API 配置：**
- **端点：** `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation`
- **认证：** Bearer Token（从 ConfigManager 读取 API Key）
- **默认模型：** `qwen-max`
- **超时：** 1800 秒（30 分钟）
- **重试：** 最多 2 次

**任务追踪：**
- 每次调用自动创建 `generate_tasks` 记录（`GenerateTaskType.CHAT`）
- 记录请求参数、模型名称、调用者类型、项目 ID 等元数据
- 成功/失败时更新任务状态

### 4. ImageService (`../../service/image_service.py`)

**作用：** 管理图片生成任务，支持分镜设计图、角色设计图、项目封面图生成。

**核心方法：**
- `generate()` - 提交图片生成任务到数据库（返回 `provider_task_id`）

**图片生成流程：**
1. 先调用 `ChatService` 生成图片提示词（文本模型）
2. 再调用 `ImageService.generate()` 提交图片生成任务（图片模型）
3. 后台轮询服务（`TaskPollingService`）自动查询任务状态并下载图片

**支持的 Provider：**
- `DashScopeImageProvider` - 阿里百炼万相文生图（wan2.6-t2i）

## 主要业务流程

### 1️⃣ 优化大纲

**入口：** QML 大纲编辑页面 → 用户点击"优化大纲"按钮

**调用链路：**
```
OutlineBridge.optimize_outline(project_id, user_requirement)
  ↓
OutlineService.optimize_outline()
  ↓
ChatService.optimize_story_outline(original_content, user_requirement)
  ↓
ChatPromptBuilder.build_outline_optimization_messages()
  ↓ 加载模板
PromptTemplateManager.get_template("outline_optimize")
  ↓ 构建 messages
PromptTemplate.build_messages(original_content=..., user_requirement=...)
  ↓ 返回
[
  {"role": "system", "content": "系统提示词"},
  {"role": "user", "content": "few-shot 示例"},
  {"role": "assistant", "content": "few-shot 回复"},
  {"role": "user", "content": "【原大纲】\n...\n【优化要求】\n..."}
]
  ↓ HTTP POST
DashScope API
  ↓ 返回优化后的大纲文本
ChatService 更新任务状态为 succeeded
  ↓
OutlineService 保存到数据库（自动触发历史版本保存）
  ↓
Bridge 发送信号通知 QML 更新 UI
```

**涉及的模板文件：** `../../prompts/templates/outline_optimize.yaml`

**任务类型：** `GenerateTaskType.CHAT`，`GenerateTaskCallerType.OUTLINE`

---

### 2️⃣ 生成剧本

**入口：** QML 剧本编辑页面 → 用户点击"生成剧本"按钮

**调用链路：**
```
ScriptBridge.generate_script(project_id)
  ↓
ScriptService.generate_script()
  ↓ 读取大纲内容
OutlineService.get_outline(project_id)
  ↓
ChatService.generate_script(outline_content)
  ↓
ChatPromptBuilder.build_script_generation_messages(outline_content)
  ↓ 加载模板
PromptTemplateManager.get_template("script_generate")
  ↓ 构建 messages
PromptTemplate.build_messages(outline_content=...)
  ↓ HTTP POST (max_tokens=16384)
DashScope API
  ↓ 返回包含 JSON 格式的剧本内容
ChatService 解析响应
  ↓
ScriptParser.parse(script_content)  # 解析 JSON 为场次列表
  ↓ 返回 (title, scenes)
ScriptService.save_script_and_scenes()
  ↓ 保存到数据库
- scripts 表：剧本元数据（标题、创建时间）
- scenes 表：场次数据（场次号、地点、时间、内容）
  ↓
Bridge 发送信号通知 QML 更新 UI
```

**涉及的模板文件：** `../../prompts/templates/script_generate.yaml`

**任务类型：** `GenerateTaskType.CHAT`，`GenerateTaskCallerType.SCRIPT`

**JSON 格式要求：**
```json
{
  "title": "剧本标题",
  "scenes": [
    {
      "scene_number": 1,
      "location": "INT",
      "time": "DAY",
      "content": "场次描述..."
    }
  ]
}
```

### 6️⃣ 生成角色设计图

**入口：** QML 角色详情页面 → 用户点击"生成设计图"按钮

**调用链路（两阶段）：**

#### 阶段 1：生成图片提示词（文本模型）
```
CharacterBridge.generate_character_design_image(character_uuid, user_requirement, visual_style)
  ↓
CharacterService.get_character(character_uuid)
  ↓
ChatService.generate_character_design_image_prompt(
    character_name, description, user_requirement, visual_style
)
  ↓
ChatPromptBuilder.build_character_design_image_prompt_messages()
  ↓ 加载模板
PromptTemplateManager.get_template("character_image_prompt")
  ↓ 构建 messages
PromptTemplate.build_messages(
    character_name=...,
    description=...,
    visual_style=...,
    visual_style_instruction=...,
    user_requirement=...
)
  ↓ HTTP POST
DashScope API
  ↓ 返回纯英文提示词（适配万相 t2i 模型）
prompt_text, task_id = ChatService.chat()
```

**涉及的模板文件：** `../../prompts/templates/character_image_prompt.yaml`

**任务类型：** `GenerateTaskType.CHAT`，`GenerateTaskCallerType.CHARACTER`

#### 阶段 2：提交图片生成任务（图片模型）
```
ImageService.generate(
    prompt=prompt_text,
    local_path="projects/{project_id}/characters/{character_uuid}.png",
    size="1280*1280",  # 1:1 比例
    caller_type=GenerateTaskCallerType.CHARACTER,
    caller_id=character_uuid,
    parent_ids=str(task_id)  # 关联文本任务
)
  ↓ 创建 generate_tasks 记录
GenerateTaskRepository.add(
    type=GenerateTaskType.IMAGE,
    provider_name="dashscope",
    model_name="wan2.6-t2i"
)
  ↓ 返回 provider_task_id
TaskPollingService 后台轮询
  ↓ 调用 DashScopeImageProvider.check_status()
  ↓ 下载图片到本地路径
  ↓ 更新任务状态为 succeeded
  ↓ 更新 Character.design_image 字段
Bridge 发送信号通知 QML 更新 UI
```

**任务类型：** `GenerateTaskType.IMAGE`，`GenerateTaskCallerType.CHARACTER`

**参数说明：**
- `size`: "1280*1280"（1:1 角色三视图）
- `negative_prompt`: ""（通常为空）
- `parent_ids`: 关联第一阶段的文本任务 ID，用于追溯调用链

### 🔟 生成分镜视频

**入口：** QML 分镜详情页面 → 用户点击"生成视频"按钮

**调用链路：**
```
StoryboardBridge.generate_shot_video(shot_id)
  ↓
ShotService.get_shot(shot_id)
  ↓ 读取角色列表
CharacterService.list_characters(project_id)
  ↓ 读取场次内容（用于场景上下文）
ScriptService.get_scene(shot.scene_number)
  ↓ 读取相邻镜头（用于连贯性提示）
ShotService.get_adjacent_shots(shot_id)
  ↓ 构建结构化 Prompt
VideoPromptBuilder.build_shot_prompt(
    shot=shot,
    scene=scene,
    characters=characters,
    prev_shot=prev_shot,
    next_shot=next_shot
)
  ↓ 返回包含以下部分的 Prompt：
【场景上下文】场次剧本内容（截断 200 字符）
【参考图片说明】分镜设计图和角色设计图的用途说明
【镜头画面】shot.content（替换角色代号为完整形象描述）
【镜头参数】景别、运镜、时长
【台词】shot.dialogue
【音效】shot.sound_effects
【连贯性提示】相邻镜头内容（截断 80 字符）
【备注】shot.notes
  ↓
VideoService.submit_video_task(
    prompt=structured_prompt,
    params={...},
    reference_images=[shot.design_image, ...character_design_images]
)
  ↓ 创建 generate_tasks 记录
GenerateTaskRepository.add(
    type=GenerateTaskType.VIDEO,
    provider_name="dashscope",
    model_name="wan2.7-t2v"
)
  ↓ 调用 DashScopeProvider.submit()
DashScope Video Generation API (HTTP POST)
  ↓ 返回 task_id
TaskPollingService 后台轮询
  ↓ 调用 DashScopeProvider.check_status()
  ↓ 下载视频到本地路径
  ↓ 自动入库到素材库（MediaService）
  ↓ 更新任务状态为 succeeded
Bridge 发送信号通知 QML 更新 UI
```

**注意：** 视频生成不直接调用文本模型，但使用 `VideoPromptBuilder` 构建结构化 Prompt，该 Prompt 中整合了角色形象描述（来自角色表）。

**任务类型：** `GenerateTaskType.VIDEO`，`GenerateTaskCallerType.STORYBOARD`

**Prompt 构建逻辑位置：** `../../prompts/video_prompt_builder.py`

## 任务追踪系统

所有文本模型调用和图片/视频生成任务都会记录在 `generate_tasks` 表中，包含以下字段：

| 字段 | 说明 |
|------|------|
| `provider_task_id` | Provider 返回的任务 ID（文本任务使用 UUID） |
| `provider_name` | Provider 名称（如 "dashscope"） |
| `model_name` | 模型名称（如 "qwen-max"、"wan2.6-t2i"） |
| `type` | 任务类型（`CHAT`/`IMAGE`/`VIDEO`） |
| `caller_type` | 调用者类型（`OUTLINE`/`SCRIPT`/`CHARACTER`/`STORYBOARD`） |
| `caller_id` | 调用者 ID（如项目 ID、角色 UUID、分镜 ID） |
| `parent_ids` | 父任务 ID（逗号分隔），用于追溯调用链 |
| `request_params` | 请求参数 JSON（包含 messages、model、module、context 等） |
| `status` | 任务状态（`pending`/`processing`/`succeeded`/`failed`） |
| `created_at` | 创建时间（毫秒时间戳） |
| `completed_at` | 完成时间（毫秒时间戳） |

**任务关联示例：**
```
文本任务 (task_id=1, type=CHAT, caller_type=CHARACTER)
  ↓ parent_ids="1"
图片任务 (task_id=2, type=IMAGE, caller_type=CHARACTER, parent_ids="1")
```

## 错误处理

### 网络错误
- **超时（1800 秒）**：最多重试 2 次，失败后更新任务状态为 `failed`
- **HTTP 错误**：立即更新任务状态为 `failed`，记录错误消息

### 解析错误
- **JSON 解析失败**：更新任务状态为 `failed`，记录错误详情
- **必填字段缺失**：抛出 `ValueError`，由上层捕获

### 任务状态追踪
- 所有错误都会更新 `generate_tasks` 表的 `status` 和 `error_message` 字段
- UI 通过 Bridge 信号获取错误通知（`task_failed` 信号）

# di/containers.py
class ApplicationContainer(containers.DeclarativeContainer):
    # 基础设施

    chat_service = providers.Singleton(

    )

        ImageService,
        config_manager=config_manager,

    )
    # ...其他 Service

## 扩展指南

### 添加新的文本模型 Prompt

1. 在 `../../prompts/templates` 创建 YAML 文件（如 `new_feature.yaml`）
2. 在 `ChatPromptBuilder` 添加构建方法（如 `build_new_feature_messages()`）

3. 在 `ImageService` 的 `_PROVIDER_REGISTRY` 注册
4. 更新 `system_capabilities.json` 配置文件

### 添加新的解析器

1. 在 `../../utils` 创建新文件（如 `xxx_parser.py`）
2. 实现 `parse()` 静态方法，接收 LLM 输出字符串，返回结构化数据
3. 在 `ChatService` 的对应方法中调用解析器
