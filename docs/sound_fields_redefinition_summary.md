# 分镜声音字段职责重新定义 - 修改总结

## 修改时间
2026-08-06

## 修改原因

用户反馈原有的声音字段划分不够清晰，需要重新定义各字段的职责：
- **角色对话**应该放在 `content` 字段中，而不是 `sound_effect`
- **sound_effect** 应该是突出的、短暂的特殊音效（脚步声、爆炸声、打雷声）
- **ambient_sound** 应该是持续存在的背景音（风声、雨声、木柴燃烧声）
- **background_music** 用于烘托气氛的配乐（激昂、安静、恐怖等情绪）

## 新的字段职责

### 1. content（镜头内容）
**职责：** 画面描述 + 人物对话台词

**包含：**
- 人物动作、表情、姿态
- 场景环境、道具细节
- **人物对话台词**（用引号标注）
- **歌唱歌词**（如有）

**示例：**
```
{CHAR_A} 坐在桌前，表情严肃专注，嘴唇清晰地动着，低声说：'我们不能再装作一切没变。'
```

### 2. sound_effect（特殊音效）
**职责：** 突出的、短暂的、需要强调的音效

**不包括：**
- ❌ 人物对话（在 content 中）
- ❌ 持续的背景音（在 ambient_sound 中）

**包括：**
- ✅ 动作音效：脚步声、敲门声、关门声、玻璃破碎
- ✅ 突发音效：爆炸声、打雷声、枪声、警报声
- ✅ 机械音效：引擎启动、齿轮转动、键盘敲击
- ✅ 特效音效：魔法施放、剑刃出鞘、8-bit音效

**示例：**
```
远处传来一声沉闷的爆炸声，震耳欲聋
```

### 3. ambient_sound（环境背景音）
**职责：** 持续存在的、构成空间氛围感的背景声音

**特点：** 持续的、弥散的、构成环境基调

**包括：**
- ✅ 自然环境：风声、雨声、流水声、树叶沙沙、鸟鸣
- ✅ 室内环境：空调嗡鸣、钟表滴答、木柴燃烧噼啪、壁炉火焰
- ✅ 城市环境：车流声、人群喧哗、地铁轰鸣、街头嘈杂

**示例：**
```
持续的雨声，雨滴敲打地面和衣服，远处城市嗡鸣
```

### 4. background_music（背景音乐）
**职责：** 烘托气氛、渲染情感的配乐

**包括：**
- ✅ 情绪描述：激昂、安静、恐怖、悲伤、欢快、紧张
- ✅ 乐器类型：钢琴独奏、交响乐团、电子合成器
- ✅ 节奏特征：节奏缓慢、鼓点密集、旋律渐强

**示例：**
```
激昂的管弦乐，鼓点密集，渲染紧张气氛
```

## 修改内容

### 1. 提示词模板优化（`prompts/templates/storyboard_generate.yaml`）

#### 1.1 content 字段说明修改

**修改前：**
```yaml
visual_content（字符串）：采用"谁+在哪+做什么"的公式。
```

**修改后：**
```yaml
content（字符串）：采用"谁+在哪+做什么+说什么"的公式。
包含人物动作、表情、关键道具、环境细节、**人物对话台词**。

人物对话处理：
- 若镜头中有人物说话，必须在 content 字段中写明具体台词，用引号标注
- 格式示例："{CHAR_A} 低声说：'我们不能再装作一切没变。'"
- 若有歌唱，需包含歌词片段
```

#### 1.2 sound_effect 字段说明修改

**修改前：**
```yaml
人声类：人物对话内容（如"他低声说：'...'"）、独白、耳语、歌唱
动作音效：脚步声、敲门声...
```

**修改后：**
```yaml
特殊音效描述，描述突出的、短暂的、需要特别强调的声音效果。
**不包括人物对话**（对话已在 content 字段中）。

常见特殊音效参考：
- 动作音效：脚步声、敲门声、关门声、玻璃破碎声
- 突发音效：爆炸声、打雷声、枪声、警报声
- 机械音效：引擎启动声、齿轮转动声、键盘敲击声
- 自然音效：闪电劈裂声、树枝折断声、冰块碎裂声

填写要求：
- 仅描述突出的、短暂的、需要强调的音效，不描述持续的背景环境音
```

#### 1.3 ambient_sound 字段说明修改

**修改前：**
```yaml
环境音描述，描述镜头中的背景环境声音。
```

**修改后：**
```yaml
环境背景音描述，描述持续存在的、构成空间氛围感的背景声音。
与 sound_effect 的区别在于：ambient_sound 是持续的、弥散的、构成环境基调的声音。

常见环境背景音参考：
- 自然环境：风声、雨声、流水声、树叶沙沙声、鸟鸣、虫鸣
- 室内环境：空调嗡鸣声、钟表滴答声、木柴燃烧的噼啪声
- 城市环境：车流声、人群喧哗声、地铁轰鸣声

填写要求：
- 描述持续存在的、弥散的背景声音，不描述突发的音效
```

#### 1.4 background_music 字段说明修改

**修改前：**
```yaml
描述镜头的配乐风格和情绪。

常见背景音乐类型参考：
- 情绪音乐：温馨快乐氛围音乐、紧张悬疑音乐...
```

**修改后：**
```yaml
描述镜头的配乐风格和情绪，用于烘托气氛、渲染情感。

常见背景音乐类型参考：
- 情绪氛围：激昂的音乐（"激昂的管弦乐，鼓点密集"）、安静的音乐、恐怖的音乐
- 紧张悬疑：快速的弦乐、不和谐音、心跳般的鼓点
- 温馨浪漫：柔和的钢琴、小提琴独奏、古典吉他

填写要求：
- 描述音乐的情绪氛围（激昂/安静/恐怖/悲伤/欢快/紧张等）
```

## 关键区别对比

### 对话处理

**修改前：**
```json
{
  "content": "{CHAR_A} 坐在桌前，表情严肃专注。",
  "sound_effect": "{CHAR_A} 低声说：'我们不能再装作一切没变。'"
}
```

**修改后：**
```json
{
  "content": "{CHAR_A} 坐在桌前，表情严肃专注，低声说：'我们不能再装作一切没变。'",
  "sound_effect": ""
}
```

### 脚步声处理

**保持不变：** 脚步声属于突出的动作音效，仍然放在 `sound_effect`

```json
{
  "sound_effect": "沉重的脚步声，靴子踩在湿滑地面上发出咔哒声"
}
```

### 持续背景音

**保持不变：** 持续的环境音仍然在 `ambient_sound`

```json
{
  "ambient_sound": "持续的雨声，雨滴敲打地面和衣服，远处城市嗡鸣"
}
```

## 用户影响

### 使用方式变化

**修改前：** 需要在 `sound_effect` 中填写对话
```json
{
  "content": "画面描述（不含对话）",
  "sound_effect": "对话内容"
}
```

**修改后：** 对话直接放在 `content` 中
```json
{
  "content": "画面描述 + 对话内容",
  "sound_effect": "突出的特殊音效"
}
```

### 优势

1. **更符合直觉**：对话是画面的一部分，放在 `content` 中更自然
2. **职责清晰**：三个声音字段职责明确，不重叠
   - `sound_effect`：突出的、短暂的音效
   - `ambient_sound`：持续的、弥散的背景音
   - `background_music`：烘托气氛的配乐
3. **易于理解**：用户更容易理解何时使用哪个字段

## 总结

本次修改重新定义了声音字段的职责划分，将人物对话从 `sound_effect` 移到 `content` 字段，使得三个声音字段的职责更加清晰：

- ✅ **content**：画面 + 对话
- ✅ **sound_effect**：突出的特殊音效（脚步声、爆炸声、打雷声）
- ✅ **ambient_sound**：持续的背景音（风声、雨声、木柴燃烧声）
- ✅ **background_music**：烘托气氛的配乐（激昂、安静、恐怖）

修改仅涉及提示词模板和文档，不影响代码逻辑和数据库结构，所有测试通过，向后兼容。
